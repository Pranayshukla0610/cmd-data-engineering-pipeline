\# CMD Data Engineering Pipeline 🚀



\## Overview

End-to-end data engineering pipeline using Windows CMD scripting, Python, and PostgreSQL.



\## Tech Stack

\- CMD (Batch Scripting)

\- Python (Pandas)

\- PostgreSQL

\- Git



\## Project Structure

cmd-data-engineering-pipeline/

│

├── data/

│ ├── raw/

│ └── processed/

├── scripts/

├── sql/

├── python/

├── logs/





\## Pipeline Steps

1\. Extract raw CSV data

2\. Transform data using Python

3\. Load data into PostgreSQL

4\. Logging and automation via CMD scripts



\## How to Run



scripts\\run\_pipeline.bat





\## Key Features

\- Fully automated pipeline

\- Error handling

\- Logging system

\- PostgreSQL integration

Brazilian E-Commerce Dataset (Olist)
